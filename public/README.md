# Public assets

## Magical Girl images (Zombie Survival)

**Title screen:** `magical-girl.png`  
- Full illustration shown on the start screen (right on desktop, top on mobile).

**In-game sprite:** `magical-girl-sprite.png`  
- Pixel art sprite shown as the hero on the left during gameplay (replaces the emoji).

1. Save each image and put it in this **`public/`** folder.
2. Use the exact filenames above so the app can find them.
3. If a file is missing, a fallback emoji is shown instead.

Paths: `maths-quiz/public/magical-girl.png` and `maths-quiz/public/magical-girl-sprite.png`
